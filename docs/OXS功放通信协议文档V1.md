# OXS功放通信协议文档V1

# 通讯方式

## 串口:

传输数据字节序均为**小端序**

当固定帧头、CRC校验（采用**CRC\-16/IBM**）、帧尾有一项校验不通过该数据将直接丢弃。

|波特率|
|---|
|115200|

# 协议格式

|Type|ENG||Byte|Description|示例值|
|---|---|---|---|---|---|
|固定帧头|Magic Header|uint32|Byte0\~3|逻辑值0x5045524F；按小端序上线字节固定为0x4F,0x52,0x45,0x50|0x5045524F|
|包长|Packet Length|uint16|Byte4\~5|总包长（包括校验位）|0x1000|
|包ID|Packet ID|uint32|Byte6\~9|包序号,在回复数据/ACK包时该ID需要原样带回用于匹配对应的命令包|0x78563412|
|包类型|Packet Type|uint8|Byte10|描述见下方具体描述|0x00|
|应答位|Ack|BOOL|Byte11|是否需要回复ACK应答<br>（非0既真）|0x01|
|命令位|Cmd|uint8|Byte12|命令位|0x00|
|数据|Payload|uint8\[\]|Byte13\~N|数据内容，不定长|0xFF|
|\.\.\.\.\.||||||
|结束帧|EndFrame|uint16|N\+1 \~ N\+2|0x5A5A|0x5A5A|
|校验位|CRC16\-IBM|uint16|N\+3 \~ N\+4|2字节，CRC16校验<br>计算范围为0\~结束帧|0xFFFF|

CRC计算范围从Magic Header到EndFrame

整包最大64字节。接收端使用256字节环形缓冲；残帧超过100 ms丢弃，并使用滑动帧头重新同步。



# 包类型

|Byte10|Desc|
|---|---|
|0x00|数据包（OXS主动发起）|
|0x01|命令包（**MCU主动发起**）|
|0x02|应答包|

**命令包由MCU主动发起、数据包由设备主动发起/代替ACK包**

以下Byte位从Payload处开始计算偏移

# 数据包

## 获取设备信息\(0x00\)

|Byte||Desc|Value|
|---|---|---|---|
|Byte0\~15|const char\[16\]|固件版本号,字符串以\\0结尾|"OXS FW v01\.23"|

## 耳机插入\(0x10\)

|Byte||Desc|Value|
|---|---|---|---|
|Byte0\~3|int32|阻抗值|**\-1代表未知, \>=0 有效**|

## 耳机拔出\(0x11\)

无payload



## 输出音量\(0x20\)

|Byte||Desc|Value|
|---|---|---|---|
|Byte0|uint8|枚举|0: 空<br>1: 外放<br>2: 耳机|
|Byte1\~4|int32|音量值|\-1代表未知,0\~100|

## 静音\(0x21\)

|Byte||Desc|Value|
|---|---|---|---|
|Byte0|uint8|枚举|0: 空<br>1: 外放<br>2: 耳机|
|Byte1|BOOL|是否静音|非0即真|

# ACK包

无错误且命令包的ACK标志位为真时应返回对应的数据包,如果有错误则返回ACK包并在Payload中附带错误值

|Byte||Desc|Value|
|---|---|---|---|
|Byte0\~3|uint32|错误码|0: 无错误应答|

错误码固定如下：

|值|含义|
|---|---|
|0|无错误|
|1|包类型错误|
|2|不支持的命令|
|3|Payload长度错误|
|4|输出枚举错误|
|5|参数越界|
|6|硬件应用失败|
|7|当前模式不允许|
