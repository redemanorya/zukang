## 1. GPIO 配置

### 1.1 GPIO 概述

B6 芯片有两组 GPIO 端口：
- **GPIOA**: 32 个引脚 (GPIOA0 ~ GPIOA31)
- **GPIOB**: 16 个引脚 (GPIOB0 ~ GPIOB15)

### 1.2 GPIO 模式配置

**头文件**: `driver/driver/inc/gpio.h`

**核心 API**:

```c
// 设置 GPIOA 端口模式
void GPIO_PortAModeSet(uint32_t pin, uint32_t mode);

// 设置 GPIOB 端口模式
void GPIO_PortBModeSet(uint32_t pin, uint32_t mode);

// 设置 GPIO 输出使能
void GPIO_RegOneBitSet(uint32_t reg, uint32_t bit);
void GPIO_RegOneBitClear(uint32_t reg, uint32_t bit);

// 读取 GPIO 输入状态
uint32_t GPIO_RegOneBitGet(uint32_t reg, uint32_t bit);
```

**模式说明**:

| 模式值 | 说明 |
|--------|------|
| 0x0000 | 普通 IO 模式 |
| 0x0001 | 复用功能 1 |
| 0x0002 | 复用功能 2 |
| ... | ... |

### 1.3 GPIO 配置示例

**示例1：配置 LED 控制引脚**

```c
// 在 gpio_config.h 中定义
#define CFG_LED_PIN    GPIOA5

// 在初始化代码中配置
void LedInit(void)
{
    // 配置为普通 IO 模式
    GPIO_PortAModeSet(CFG_LED_PIN, 0x0000);
    
    // 使能输出
    GPIO_RegOneBitSet(GPIO_A_OE, GPIO_INDEX5);
}

// 控制 LED
void LedOn(void)
{
    GPIO_RegOneBitSet(GPIO_A_OUT, GPIO_INDEX5);
}

void LedOff(void)
{
    GPIO_RegOneBitClear(GPIO_A_OUT, GPIO_INDEX5);
}
```

**示例2：配置按键输入引脚**

```c
// 在 gpio_config.h 中定义
#define CFG_KEY_PIN    GPIOA10

// 在初始化代码中配置
void KeyInit(void)
{
    // 配置为普通 IO 模式
    GPIO_PortAModeSet(CFG_KEY_PIN, 0x0000);
    
    // 禁用输出（输入模式）
    GPIO_RegOneBitClear(GPIO_A_OE, GPIO_INDEX10);
    
    // 使能输入
    GPIO_RegOneBitSet(GPIO_A_IE, GPIO_INDEX10);
    
    // 配置为上拉
    GPIO_RegOneBitSet(GPIO_A_PU, GPIO_INDEX10);
}

// 读取按键状态
bool IsKeyPressed(void)
{
    return (GPIO_RegOneBitGet(GPIO_A_IN, GPIO_INDEX10) == 0);  // 低电平表示按下
}
```

### 1.4 GPIO 复用功能

B6 芯片的 GPIO 支持多种复用功能，如 UART、I2C、SPI、PWM 等。

**示例：配置 UART 引脚**

```c
// 在 gpio_config.h 中定义
#define CFG_UART_TX_PORT    GPIOA0
#define CFG_UART_RX_PORT    GPIOA1

// 在初始化代码中配置
void UartGpioInit(void)
{
    // 配置为 UART 复用功能（具体模式值需查阅芯片手册）
    GPIO_PortAModeSet(CFG_UART_TX_PORT, 0x0001);  // UART_TX
    GPIO_PortAModeSet(CFG_UART_RX_PORT, 0x0001);  // UART_RX
}
```

## 2. UART 配置

### 2.1 UART 概述

B6 芯片支持多个 UART 接口：
- **UART0**: 调试串口（默认）
- **UART1**: 可配置为通用串口
- **UART2**: 可配置为通用串口

### 2.2 UART 初始化

**头文件**: `driver/driver/inc/uarts.h`

**核心 API**:

```c
// UART 初始化
void DbgUartInit(uint32_t uart, uint32_t baudrate, uint8_t dataBits, uint8_t parity, uint8_t stopBits);

// UART 发送数据
void UartSendData(uint32_t uart, uint8_t* data, uint16_t len);

// UART 接收数据
uint16_t UartRecvData(uint32_t uart, uint8_t* data, uint16_t len);
```

**初始化示例**:

```c
// 在 main.c 中初始化调试串口
void LogUartConfig(bool InitBandRate)
{
    #ifdef CFG_UART_LOG_EN
    // 配置 GPIO 为 UART 复用功能
    SET_PIN_MODE(CFG_UART_TX_PORT, GET_UARTIO_MODE(CFG_UART_TX_PORT));
    
    if(InitBandRate) {
        // 初始化 UART：115200 波特率，8 数据位，无校验，1 停止位
        DbgUartInit(GET_UARTIO_UARTX(CFG_UART_TX_PORT), 115200, 8, 0, 1);
    }
    #endif
}
```

### 2.3 UART 打印调试

SDK 提供 `APP_DBG()` / `DBG()` 宏用于调试打印：

```c
// 在代码中使用
APP_DBG("Driver Version: %s\n", GetLibVersionDriver());
DBG("Main task MSG_POWER\n");
```

**日志开关**（`app_config.h`）:
```c
#define CFG_UART_LOG_EN    // 启用 UART 日志
```

## 3. I2C 配置

### 3.1 I2C 概述

B6 芯片支持 I2C 主从模式，可连接各种 I2C 外设（如 EEPROM、传感器等）。

### 3.2 I2C 初始化

**头文件**: `driver/driver/inc/i2c.h`

**核心 API**:

```c
// I2C 初始化
void I2C_Init(uint32_t module, uint32_t clock);

// I2C 写数据
int32_t I2C_MasterWrite(uint8_t module, uint8_t devAddr, uint8_t* data, uint16_t len);

// I2C 读数据
int32_t I2C_MasterRead(uint8_t module, uint8_t devAddr, uint8_t* data, uint16_t len);
```

**初始化示例**:

```c
// 在初始化代码中配置
void I2cInit(void)
{
    // 配置 GPIO 为 I2C 复用功能
    GPIO_PortAModeSet(GPIOA2, 0x0002);  // I2C_SCL
    GPIO_PortAModeSet(GPIOA3, 0x0002);  // I2C_SDA
    
    // 初始化 I2C：100kHz 时钟
    I2C_Init(I2C0_MODULE, 100000);
}
```

## 4. DMA 配置

### 4.1 DMA 概述

B6 芯片有两个 DMA 控制器：
- **DMA0**: 8 个通道
- **DMA1**: 8 个通道

### 4.2 DMA 通道分配

**核心 API**:

```c

void DMA_ChannelAllocTableSet(uint32_t dma, uint8_t* table);

// DMA 传输配置
void DMA_Config(uint32_t channel, uint32_t srcAddr, uint32_t dstAddr, uint32_t len);
```

**初始化示例**（`main_task.c`）:

```c
// DMA0 通道分配表
static const uint8_t Dma0ChannelMap[16] = {
    MAP0_COMMON_FIRST
    /*...*/
};

// DMA1 通道分配表

    MAP1_COMMON_FIRST

DMA_ChannelAllocTableSet(DMA1, (uint8_t*)Dma1ChannelMap);
```

## 11. 按键处理

### 11.1 按键类型

SDK 支持多种按键类型：
- **ADC 按键**: 通过电阻分压检测多个按键
- **IO 按键**: 通过 GPIO 直接检测
- **IR 遥控**: 通过红外接收头检测
- **编码器**: 通过旋转编码器检测

### 11.2 ADC 按键配置

**头文件**: `app_src/hmi/key/adc_key.h`

**配置步骤**:

1. **在 `gpio_config.h` 中定义 ADC 按键引脚**:
```c
#define CFG_ADC_KEY_PIN    GPIOA20  // ADC 按键引脚
```

2. **在 `adc_levels.h` 中定义按键电平**:
```c
// ADC 按键电平分级
#define ADC_KEY_LEVEL_0    0        // 无按键
#define ADC_KEY_LEVEL_1    500      // 按键1
#define ADC_KEY_LEVEL_2    1000     // 按键2
#define ADC_KEY_LEVEL_3    1500     // 按键3
```

3. **初始化 ADC 按键**:
```c
void AdcKeyInit(void)
{
    // 配置 GPIO 为 ADC 复用功能
    GPIO_PortAModeSet(CFG_ADC_KEY_PIN, 0x0003);  // ADC 模式
    
    // 初始化 SAR ADC
    SarADC_Init();
}
```

### 11.3 IO 按键配置

**头文件**: `app_src/hmi/key/io_key.h`

**配置步骤**:

1. **在 `gpio_config.h` 中定义 IO 按键引脚**:
```c
#define CFG_IO_KEY_PIN    GPIOA10  // IO 按键引脚
```

2. **初始化 IO 按键**:
```c
void IoKeyInit(void)
{
    // 配置 GPIO 为输入模式
    GPIO_PortAModeSet(CFG_IO_KEY_PIN, 0x0000);
    GPIO_RegOneBitClear(GPIO_A_OE, GPIO_INDEX10);
    GPIO_RegOneBitSet(GPIO_A_IE, GPIO_INDEX10);
    GPIO_RegOneBitSet(GPIO_A_PU, GPIO_INDEX10);  // 上拉
}
```

## 12. LED 显示

### 12.1 LED 类型

SDK 支持多种 LED 显示方式：
- **普通 LED**: 通过 GPIO 控制
- **PWM LED**: 通过 PWM 控制亮度
- **数码管**: 通过段码显示
- **RGB LED**: 通过 PWM DMA 控制

### 12.2 普通 LED 配置

**配置步骤**:

1. **在 `gpio_config.h` 中定义 LED 引脚**:
```c
#define CFG_LED_PIN    GPIOA5  // LED 控制引脚
```

2. **初始化 LED**:
```c
void LedInit(void)
{
    // 配置 GPIO 为输出模式
    GPIO_PortAModeSet(CFG_LED_PIN, 0x0000);
    GPIO_RegOneBitSet(GPIO_A_OE, GPIO_INDEX5);
}
```

3. **控制 LED**:
```c
void LedOn(void)
{
    GPIO_RegOneBitSet(GPIO_A_OUT, GPIO_INDEX5);
}

void LedOff(void)
{
    GPIO_RegOneBitClear(GPIO_A_OUT, GPIO_INDEX5);
}
```

### 12.3 PWM LED 配置

**配置步骤**:

1. **在 `gpio_config.h` 中定义 PWM LED 引脚**:
```c
#define CFG_PWM_LED_PIN    GPIOA6  // PWM LED 引脚
```

2. **初始化 PWM LED**:
```c
void PwmLedInit(void)
{
    // 配置 GPIO 为 PWM 复用功能
    GPIO_PortAModeSet(CFG_PWM_LED_PIN, 0x0004);  // PWM 模式
    
    // 初始化 PWM：1kHz 频率，50% 占空比
    PWM_Init(PWM0_MODULE, 1000, 50);
}
```

3. **控制 LED 亮度**:
```c
void PwmLedSetBrightness(uint8_t brightness)
{
    // brightness: 0~100
    PWM_DutySet(PWM0_MODULE, brightness);
}
```

## 15. 典型应用场景

### 15.1 按键 + LED 控制

**场景**: 按下按键时点亮 LED，松开时熄灭

**实现**:
```c
// 按键扫描任务
void KeyScanTask(void)
{
    while(1) {
        if(IsKeyPressed()) {
            LedOn();
        } else {
            LedOff();
        }
        osTaskDelay(10);  // 10ms 扫描周期
    }
}
```

### 15.2 温度监控 + 动态调压

**场景**: 根据温度动态调整核心电压，降低功耗

**实现**（`main_task.c`）:

```c
// 温度监控
void TemperatureMonitor(void)
{
    uint8_t temp = TemperatureGet();
    
    if(temp >= 60) {
        // 高温：降低电压
        Power_ConfigDCDC11(PWD_DCDC11_LVL_1V1);
    } else {
        // 常温：正常电压
        Power_ConfigDCDC11(PWD_DCDC11_LVL_1V23);
    }
}
```

### 15.3 蓝牙 + 音频播放

**场景**: 蓝牙连接后自动播放音频

**实现**:

1. **在 `bt_config.h` 中配置蓝牙**:
```c
#define CFG_BT_NAME    "MySpeaker"
#define BT_SUPPORT     ENABLE
```

2. **在 `app_config.h` 中启用蓝牙模式**:
```c
#define CFG_APP_BT_MODE_EN
```

3. **蓝牙连接回调**（`bt_app_connect.c`）:
```c
void BtConnectCallback(uint8_t status)
{
    if(status == BT_CONNECTED) {
        // 切换到蓝牙播放模式
        SysModeEnter(ModeBtAudioPlay);
    }
}
```
