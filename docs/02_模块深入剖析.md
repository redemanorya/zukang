## 1. 五层架构详解

SDK 采用五层分层架构，从底层硬件驱动到顶层应用模式，各层职责明确、接口清晰。

```
┌─────────────────────────────────────────────────────────────────┐
│                     app_src (应用层)                              │
│  main.c / main_task.c / app_mode_* / components / hmi / power   │
│  system_config / startup / tuya_app / mv_app / mv_upgrade        │
├─────────────────────────────────────────────────────────────────┤
│                  app_framework (框架引擎层)                       │
│  mode_engine / audio_engine / bluetooth_engine                   │
│  slow_device_engine / wireless2_engine                            │
├─────────────────────────────────────────────────────────────────┤
│                   middleware (中间件层)                           │
│  rtos / audio / bluetooth / roboeffect / fatfs / otg_host        │
│  dual_core / flashboot / rtc / cec / mv_utils / lrc              │
├─────────────────────────────────────────────────────────────────┤
│                  driver_api (驱动API层)                           │
│  封装driver接口 + 集成OS信号量/队列                                │
├─────────────────────────────────────────────────────────────────┤
│                    driver (硬件驱动层)                            │
│  GPIO / UART / I2C / SPI / DMA / DAC / ADC / I2S / SPDIF         │
│  USB(OTG) / SDIO / Timer / PWM / Watchdog / PMU / IR / Flash     │
└─────────────────────────────────────────────────────────────────┘
```

### 1.1 层间调用关系

| 上层 | 调用 | 下层 | 说明 |
|------|------|------|------|
| app_src | → | app_framework | 通过模式引擎/音频引擎接口 |
| app_framework | → | middleware | 通过中间件 API（rtos/audio/bluetooth） |
| middleware | → | driver_api | 通过驱动 API 接口 |
| driver_api | → | driver | 通过寄存器级驱动 |

### 1.2 关键头文件依赖

```c
// app_src/main.c 中的关键 include
#include "gpio.h"              // driver 层
#include "uarts.h"             // driver 层
#include "dma.h"               // driver 层
#include "timer.h"             // driver 层
#include "FreeRTOS.h"          // middleware/rtos
#include "task.h"              // middleware/rtos
#include "queue.h"             // middleware/rtos
#include "mode_task.h"         // app_framework/mode_engine
#include "audio_core_service.h" // app_framework/audio_engine
#include "bt_stack_service.h"   // app_framework/bluetooth_engine
#include "bt_common_api.h"     // middleware/bluetooth
#include "audio_effect_control.h" // app_src/components/audio
```

### 2.2 关键驱动模块

#### 2.2.1 GPIO 驱动

**头文件**: `driver/driver/inc/gpio.h`

**核心功能**:
- GPIO 端口模式配置（输入/输出/复用功能）
- GPIO 中断配置（边沿/电平触发）
- GPIO 上下拉配置

**典型应用**:
```c
// 配置 GPIO 为输出模式
GPIO_PortAModeSet(GPIOA5, 0x0000);  // 普通 IO 模式
GPIO_RegOneBitSet(GPIO_A_OE, GPIO_INDEX5);  // 使能输出

// 配置 GPIO 为输入模式（带中断）
GPIO_PortAModeSet(GPIOA10, 0x0000);
GPIO_RegOneBitClear(GPIO_A_OE, GPIO_INDEX10);  // 禁用输出
GPIO_RegOneBitSet(GPIO_A_IE, GPIO_INDEX10);    // 使能输入
```

#### 2.2.2 UART 驱动

**头文件**: `driver/driver/inc/uarts.h`

**核心功能**:
- UART 初始化（波特率、数据位、停止位、校验位）
- UART 发送/接收
- UART 中断处理

**典型应用**:
```c
// 初始化 UART（调试串口）
DbgUartInit(UART0, 115200, 8, 0, 1);  // 8数据位，无校验，1停止位

// 发送数据
UartSendData(UART0, buffer, len);
```

#### 2.2.3 DMA 驱动

**头文件**: `driver/driver/inc/dma.h`

**核心功能**:
- DMA 通道分配
- DMA 传输配置（源地址、目标地址、长度）
- DMA 中断处理

**典型应用**:
```c
// DMA 通道分配表（在 main_task.c 中配置）
static const uint8_t Dma0ChannelMap[16] = {
    MAP0_COMMON_FIRST
    /*...*/
};

// 设置 DMA 通道分配
DMA_ChannelAllocTableSet(DMA0, (uint8_t*)Dma0ChannelMap);
```

#### 2.2.4 DAC 驱动

**头文件**: `driver/driver/inc/dac.h`

**核心功能**:
- DAC 初始化（采样率、位宽、FIFO）
- DAC 电源管理
- DAC 音量控制

**典型应用**:

```c
AUDIODAC_ParamCt DacParamCt = {
```

#### 2.2.5 ADC 驱动

**头文件**: `driver/driver/inc/adc.h` 和 `audio_adc.h`

**核心功能**:
- SAR ADC 初始化（按键检测）

**典型应用**:

## 3. Driver API 层深入

### 3.1 Driver API 层职责

Driver API 层在底层 driver 之上封装了一层 OS 集成接口：

1. **封装常用通讯接口**（I2C/SPI/UART 等），集成 DMA 传输
2. **集成 FreeRTOS 信号量和队列**，为上层提供线程安全的驱动调用
3. **对上层提供统一 API**，屏蔽底层寄存器操作细节

### 3.2 典型封装示例

**I2C 接口封装**:
```c
// driver_api/src/i2c_interface.c
int32_t I2C_MasterWrite(uint8_t module, uint8_t devAddr, uint8_t* data, uint16_t len)
{
    // 获取信号量
    osSemaphoreWait(i2c_sem, osWaitForever);
    
    // 配置 DMA 传输
    DMA_Config(...);
    
    // 启动传输
    I2C_Start(...);
    
    // 等待完成
    osSemaphoreWait(i2c_done_sem, timeout);
    
    // 释放信号量
    osSemaphoreRelease(i2c_sem);
    
    return 0;
}
```

## 6. App Src 层深入

### 6.1 主任务 (main_task.c)

**核心职责**:
- 系统初始化（`SystemInit()`）
- 消息主循环（`MainAppTaskEntrance()`）
- 公共消息处理（`PublicMsgPross()`）
- 温度监控（`TemperatureMonitor()`）

**关键代码流程**:
```c
static void MainAppTaskEntrance(void * param)
{
    SystemInit();  // 系统初始化
    
    while(1) {
        // 温度监控
        vmid_Dynamic_change(TemperatureMonitor());
        
        // 接收消息
        MessageRecv(mainAppCt.msgHandle, &msg, MAIN_APP_MSG_TIMEOUT);
        
        // 公共检测
        PublicDetect();
        
        // 公共消息处理
        PublicMsgPross(msg);
        
        // 设备服务处理
        DeviceServicePocess(msg.msgId);
        
        // 模式切换生成
        if(msg.msgId != MSG_NONE) {
            SysModeGenerate(msg.msgId);
            if(!AudioEffect_Msg_Check(&msg.msgId)) {
                MessageSend(GetSysModeMsgHandle(), &msg);
            }
        }
        
        // 模式切换超时处理
        SysModeChangeTimeoutProcess();
        
        // 喂狗
        WDG0_Feed();
    }
}
```

## 7. 消息驱动架构

| 消息组 | 起始ID | 用途 |
|--------|--------|------|
| `MSG_MAINAPP_*` | 0x0100 | 主应用消息 |
| `MSG_BT_PLAY_*` | 0x0400 | 蓝牙播放模式 |
| `MSG_BT_HF_*` | 0x0500 | 蓝牙通话模式 |
| `MSG_LINE_AUDIO_*` | 0x0700 | LineIn 模式 |
| `MSG_HDMI_AUDIO_*` | 0x0800 | HDMI 模式 |
| `MSG_RADIO_*` | 0x0A00 | FM 收音模式 |
| `MSG_USB_DEVICE_*` | 0x0B00 | USB 设备模式 |
| `MSG_I2SIN_AUDIO_*` | 0x0D00 | I2S 输入模式 |
| `MSG_TWS_SLAVE_*` | 0x0E00 | TWS 从机模式 |
| `MSG_BTSTACK_*` | 0x7900 | 蓝牙协议栈服务 |
| `MSG_MEDIA_RECORDER_*` | 0x7800 | 录音服务 |

### 7.2 消息流

```
按键/设备事件 → DeviceService → MSG_DEVICE_SERVICE_xxx
                                    ↓
                           MainAppTask 消息循环
                                    ↓
                    ┌───────────────┼───────────────┐
                    ↓               ↓               ↓
              SysModeGenerate   PublicMsgPross   AudioEffect_Msg_Check
              (模式切换)        (公共消息处理)     (音效消息过滤)
                    ↓               ↓               ↓
              SysModeTask      各模式任务      AudioCore服务
              (模式引擎)       (BtPlay等)      (音频核心)
```

### 7.3 关键消息处理函数

| 函数 | 所在文件 | 职责 |
|------|----------|------|
| `PublicMsgPross()` | main_task.c | 处理主循环公共消息 |
| `SysModeGenerate()` | mode_engine/mode_task.c | 根据消息生成模式切换 |
| `DeviceServicePocess()` | app_src/hmi/detect/device_detect.c | 处理设备插拔检测 |
| `AudioEffect_Msg_Check()` | app_src/components/audio/audio_effect_control.c | 过滤音效相关消息 |

## 8. AudioCore 音频核心

### 8.1 核心数据结构

定义在 `app_framework/audio_engine/audio_core_api.h`：

```c
// 音频源结构
typedef struct _AudioCoreSource {
    bool    Enable;        // 通道使能
    bool    Sync;          // 同步标志（TRUE=每帧同步等待）
    uint8_t Channels;      // PCM通道数
    uint8_t PcmWidth;      // PCM位宽
    uint8_t FlowCh;        // Flow通道数
    uint8_t FlowWidth;     // Flow位宽
    bool    Active;        // 活跃状态
    uint8_t Net;           // 网络编号（DefaultNet=0）
    AudioCoreDataGetFunc DataGetFunc;   // 数据获取回调
    AudioCoreDataLenFunc DataLenFunc;   // 数据长度回调
    PCM_DATA_TYPE *PcmInBuf;           // 输入PCM缓冲区
    SRC_ADAPTER *SrcAdapter;           // 采样率转换适配器
} AudioCoreSource;

// 音频输出结构
typedef struct _AudioCoreSink {
    bool    Enable;        // 通道使能
    bool    Sync;          // 同步标志
    uint8_t Channels;      // PCM通道数
    uint8_t PcmWidth;      // PCM位宽

} AudioCoreSink;
```

## 9. 模式引擎

### 9.1 模式生命周期

```
模式切换触发（消息/按键/设备插入）
  ↓
旧模式 Deinit（释放资源）
  ↓
新模式 Init（初始化音频通路、效果链路）
  ↓
新模式 Run（进入运行循环）
  ↓
等待下一次切换
```

### 9.2 模式切换流程

```c
// 模式切换消息处理
void SysModeGenerate(uint16_t Msg)
{
    switch(Msg) {
        case MSG_DEVICE_SERVICE_BTPLAY_IN:
            // 切换到蓝牙播放模式
            SysModeEnter(ModeBtAudioPlay);
            break;
        case MSG_DEVICE_SERVICE_USB_DEVICE_IN:
            // 切换到 USB 设备模式
            SysModeEnter(ModeUsbDevicePlay);
            break;
        // ...
    }
}
```

### 9.3 模式注册

在 `mode_parameter.h` 中注册所有模式：

```c
volatile SysModeStruct SysMode[] = {
    {ModeIdle, IdleModeInit, IdleModeDeinit, IdleModeRun, ModeStateReady},
    {ModeBtAudioPlay, BtPlayInit, BtPlayDeinit, BtPlayRun, ModeStateInit},
    {ModeUsbDevicePlay, UsbDevicePlayInit, UsbDevicePlayDeinit, UsbDevicePlayRun, ModeStateReady},
    // ...
};
```

### 12.2 音效参数 (audio_effect.bin)

- 由 **ACPWorkbench** 工具生成
- 通过 `tools/merge_script/merge.exe` 合并到固件
- `merge.ini` 配置：路径 `audioeffect_res/audio_effect.bin`，最大长度 0x12000
- 运行时由 `AudioEffect_Parambin_Check()` 校验，失败则进入 Safe Mode

## 13. 任务调度与优先级

SDK 使用 FreeRTOS 多任务调度，各核心任务的优先级和栈大小如下：

| 任务名 | 优先级 | 栈大小 | 职责 |
|--------|--------|--------|------|
| MainAppTask | 4 | 640 words | 主任务：消息循环、模式调度、温度监控 |
| SysModeTask | 未明确 | 未明确 | 模式引擎任务 |
| AudioCoreService | 5 | 768 bytes | 音频核心服务 |
| EffectService | 6 | 512 bytes | 音效处理服务 |
| BtStackService | 见bt_stack_service.h | 见bt_stack_service.h | 蓝牙协议栈服务 |
| SlowDeviceTask | 未明确 | 未明确 | 慢速设备处理 |
| ShellTask | 2 | 512 words | Shell 命令处理 |

**优先级说明**: 数值越大优先级越高。EffectService(6) > AudioCoreService(5) > MainAppTask(4) > ShellTask(2)
