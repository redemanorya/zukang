## 1. 新增音频模式

### 1.1 场景描述

假设需要新增一个自定义音频模式（如 `CustomMode`），用于特定的音频输入源。

### 1.2 开发步骤

**步骤1：创建模式文件**

在 `app_src/` 下新建 `app_mode_custom/` 目录，创建 `custom_mode.c/h`：

```c
// custom_mode.h
#ifndef __CUSTOM_MODE_H__
#define __CUSTOM_MODE_H__

#include "mode_task.h"

bool CustomModeInit(void);
bool CustomModeDeinit(void);
void CustomModeRun(uint16_t msgId);

#endif
```

```c
// custom_mode.c
#include "custom_mode.h"
#include "audio_core_api.h"
#include "audio_effect_control.h"

bool CustomModeInit(void)
{
    // 初始化音频通路
    // 1. 配置 Source（输入源）
    AudioCoreSourceConfig(APP_SOURCE_NUM, 48000, 2, 24);
    
    // 2. 配置 Sink（输出端）
    AudioCoreSinkConfig(DAC_SINK_NUM, 48000, 2, 24);
    
    // 3. 初始化音效链路
    AudioEffect_FlowSwitch(0);  // 使用 Flow 0
    
    return true;
}

bool CustomModeDeinit(void)
{
    // 释放资源
    AudioCoreSourceDisable(APP_SOURCE_NUM);
    AudioCoreSinkDisable(DAC_SINK_NUM);
    
    return true;
}

void CustomModeRun(uint16_t msgId)
{
    // 运行循环
    switch(msgId) {
        case MSG_CUSTOM_MODE_START:
            // 开始播放
            break;
        case MSG_CUSTOM_MODE_STOP:
            // 停止播放
            break;
        // ...
    }
}
```

**步骤2：注册模式**

在 `app_src/app_mode/mode_parameter.h` 中注册模式：

```c
// 添加模式编号
typedef enum {
    ModeIdle = 0,
    ModeBtAudioPlay,
    // ...
    ModeCustomPlay,  // 新增
    ModeSafe,
    SysModeMax,
} SysModeNumber;

// 添加模式名称映射
const SysModeStrAndRemind ModeNameStr[] = {
    {ModeIdle, "Idle"},
    {ModeBtAudioPlay, "BtPlay"},
    // ...
    {ModeCustomPlay, "CustomPlay"},  // 新增
    {ModeSafe, "Safe"},
};

// 添加模式结构
volatile SysModeStruct SysMode[] = {
    {ModeIdle, IdleModeInit, IdleModeDeinit, IdleModeRun, ModeStateReady},
    {ModeBtAudioPlay, BtPlayInit, BtPlayDeinit, BtPlayRun, ModeStateInit},
    // ...
    {ModeCustomPlay, CustomModeInit, CustomModeDeinit, CustomModeRun, ModeStateReady},  // 新增
    {ModeSafe, SafeModeInit, SafeModeDeinit, SafeModeRun, ModeStateSusend},
};
```

**步骤3：配置功能开关**

在 `app_src/system_config/app_config.h` 中添加：

```c
#define CFG_APP_CUSTOM_MODE_EN    // 启用自定义模式
```

**步骤4：配置音效图**

在 `app_src/system_config/flow_config.h` 中配置 Source/Sink：

```c
// 添加自定义 Source
#define AUDIO_SOURCE_ENUM_MAP(XX) \
    // ... 现有 Source
    XX(CUSTOM_SOURCE_NUM, "CUSTOM_SOURCE")

// 添加自定义 Sink
#define AUDIO_SINK_ENUM_MAP(XX) \
    // ... 现有 Sink
    XX(CUSTOM_SINK_NUM, "CUSTOM_SINK")
```

**步骤5：编译验证**

重新编译工程，烧录到目标板，验证新模式是否正常工作。

## 2. 修改音效参数

### 2.1 场景描述

需要修改音效参数（如 EQ、混响等），并验证效果。

### 2.2 开发步骤

**步骤1：使用 ACPWorkbench 配置音效**

1. 打开 ACPWorkbench V5.8.2
2. 加载 `audioeffect_res/audio_effect.bin`
3. 选择目标 Flow（如 `Karaoke`）
4. 修改音效参数（如 EQ、Reverb、Pitch Shifter 等）
5. 导出新的 `audio_effect.bin` 到 `audioeffect_res/` 目录

**步骤2：重新编译固件**

```bash
# 在 AndeSight 中 Clean + Build（推荐，postbuild 会自动重新合并音效参数）
# 或仅重新合并分区（不重新编译代码）：在 Release 目录下执行
cd /d d:\MVS_err\workspace\B6_Audio_SDK\Release
..\tools\script_post.bat
```

> 说明：audio_effect.bin 是在 postbuild 阶段由 `merge.exe` 合并进固件的，因此修改音效参数后无需改动代码，重新执行 postbuild（或整体 Build）即可生效。

**步骤3：烧录验证**

烧录新的固件到目标板，观察音效变化。

### 2.3 常用音效配置

| 音效类型 | 配置方法 | 说明 |
|----------|----------|------|
| EQ | 在 ACPWorkbench 中选择 `music_EQ` 或 `mic_EQ` | 调整各频段增益 |
| 混响 | 在 ACPWorkbench 中选择 `reverb_plate_me0` | 调整混响时间、湿声比例 |
| 变声 | 在 ACPWorkbench 中选择 `pitch_shifter0` | 调整音高偏移 |
| 降噪 | 在 ACPWorkbench 中选择 `blue_ns0` | 调整降噪强度 |
| AEC | 在 ACPWorkbench 中选择 `blue_aec0` | 调整回声消除参数 |

## 3. 添加自定义提示音

### 3.1 场景描述

需要添加一个新的提示音（如 `custom.mp3`），并在特定事件时播放。

### 3.2 开发步骤

**步骤1：准备提示音文件**

1. 准备 MP3 提示音文件（如 `custom.mp3`，文件名不超过 8 个字符）
2. 放入 `remind_res/` 目录（如需 16kHz 采样率版本，放入 `remind_res/16K/`）

**步骤2：重新编译（自动生成提示音资源）**

提示音资源在 **prebuild 阶段自动生成**，无需手动编辑任何头文件：

- `script.bat` 调用 ffmpeg 将 MP3 转为 MP2，再由 `MergeAudio2BinNew.exe` 合并为 `tools/remind_script/all.bin`
- 同时自动生成 `sound_remind_item.h`（文件头标注 "Automatic generated"），并同步到 `app_framework/audio_engine/remind_sound_item.h`
- 每个 MP3 文件按文件名自动生成对应宏，如 `custom.mp3` → `SOUND_REMIND_CUSTOM`（宏名为文件名大写、截断至 8 字符）

> 注意：`sound_remind_item.h` 是自动生成文件，**不要手动编辑**（每次编译都会被覆盖）。
> 如需不编译代码仅重建提示音，可在 `Release` 目录下运行 `..\tools\script_MP3.bat`。

**步骤3：调用提示音播放**

在代码中调用提示音播放 API：

```c
// 播放自定义提示音（宏名由文件名自动生成）
void PlayCustomPrompt(void)
{
    RemindSoundPlay(SOUND_REMIND_CUSTOM);
}
```

**步骤4：验证**

重新编译后，提示音数据已通过 postbuild 的 `merge.exe` 合并进固件（`[remind]` 分区，最大 0x2A000）。烧录 `main_merge.MVA.bin` 到目标板，验证提示音播放。

## 4. 实现按键功能

### 4.1 场景描述

需要实现按键功能（如短按播放/暂停、长按切换模式等）。

### 4.2 开发步骤

**步骤1：配置按键**

在 `app_src/system_config/gpio_config.h` 中定义按键引脚：

```c
#define CFG_KEY_PLAY_PIN    GPIOA10  // 播放/暂停按键
#define CFG_KEY_MODE_PIN    GPIOA11  // 模式切换按键
```

**步骤2：初始化按键**

在 `app_src/hmi/key/io_key.h` 中初始化：

```c
void IoKeyInit(void)
{
    // 配置播放/暂停按键
    GPIO_PortAModeSet(CFG_KEY_PLAY_PIN, 0x0000);
    GPIO_RegOneBitClear(GPIO_A_OE, GPIO_INDEX10);
    GPIO_RegOneBitSet(GPIO_A_IE, GPIO_INDEX10);
    GPIO_RegOneBitSet(GPIO_A_PU, GPIO_INDEX10);
    
    // 配置模式切换按键
    GPIO_PortAModeSet(CFG_KEY_MODE_PIN, 0x0000);
    GPIO_RegOneBitClear(GPIO_A_OE, GPIO_INDEX11);
    GPIO_RegOneBitSet(GPIO_A_IE, GPIO_INDEX11);
    GPIO_RegOneBitSet(GPIO_A_PU, GPIO_INDEX11);
}
```

**步骤3：按键扫描**

在 `app_src/hmi/key/key.c` 中实现按键扫描：

```c
void KeyScan(void)
{
    static uint32_t playKeyPressTime = 0;
    static uint32_t modeKeyPressTime = 0;
    
    // 检测播放/暂停按键
    if(GPIO_RegOneBitGet(GPIO_A_IN, GPIO_INDEX10) == 0) {
        if(playKeyPressTime == 0) {
            playKeyPressTime = osTaskGetTickCount();
        }
    } else {
        if(playKeyPressTime > 0) {
            uint32_t pressDuration = osTaskGetTickCount() - playKeyPressTime;
            
            if(pressDuration < 500) {
                // 短按：播放/暂停
                MessageSend(GetMainMessageHandle(), MSG_KEY_PLAY_PAUSE);
            } else {
                // 长按：停止
                MessageSend(GetMainMessageHandle(), MSG_KEY_STOP);
            }
            
            playKeyPressTime = 0;
        }
    }
    
    // 检测模式切换按键
    if(GPIO_RegOneBitGet(GPIO_A_IN, GPIO_INDEX11) == 0) {
        if(modeKeyPressTime == 0) {
            modeKeyPressTime = osTaskGetTickCount();
        }
    } else {
        if(modeKeyPressTime > 0) {
            uint32_t pressDuration = osTaskGetTickCount() - modeKeyPressTime;
            
            if(pressDuration < 500) {
                // 短按：切换模式
                MessageSend(GetMainMessageHandle(), MSG_KEY_MODE_SWITCH);
            }
            
            modeKeyPressTime = 0;
        }
    }
}
```

**步骤4：消息处理**

在 `main_task.c` 的 `PublicMsgPross()` 中处理按键消息：

```c
static void PublicMsgPross(MessageContext msg)
{
    switch(msg.msgId) {
        case MSG_KEY_PLAY_PAUSE:
            // 播放/暂停
            if(GetSystemMode() == ModeBtAudioPlay) {
                BtPlayPause();
            }
            break;
            
        case MSG_KEY_MODE_SWITCH:
            // 切换模式
            SysModeEnter(ModeIdle);
            break;
            
        // ...
    }
}
```

**步骤5：编译验证**

重新编译工程，烧录到目标板，验证按键功能。

## 5. 配置低功耗模式

### 5.1 场景描述

需要配置低功耗模式（DeepSleep），以降低功耗。

### 5.2 开发步骤

**步骤1：启用 DeepSleep**

在 `app_src/system_config/app_config.h` 中启用：

```c
#define CFG_IDLE_MODE_DEEP_SLEEP    // 启用 DeepSleep
```

**步骤2：配置唤醒源**

在 `app_src/power/deepsleep.c` 中配置唤醒源：

```c
void DeepSleepWakeupConfig(void)
{
    // 配置 GPIO 唤醒
    GPIO_PortAModeSet(GPIOA10, 0x0000);
    GPIO_RegOneBitSet(GPIO_A_IE, GPIO_INDEX10);
    
    // 配置 RTC 唤醒
    RTC_WakeupConfig(RTC_WAKEUP_TIMER, 60);  // 60秒定时唤醒
}
```

**步骤3：配置睡眠流程**

在 `main.c` 的 `SleepMain()` 中配置：

```c
void SleepMain(void)
{
    // 关闭 DAC
    AudioDAC_AllPowerDown();
    
    // 切换时钟到 RC
    Clock_UARTClkSelect(RC_CLK_MODE);
    LogUartConfig(TRUE);
    
    // 关闭 PLL
    Clock_DPllClose(DPLL0_MODULE);
    Clock_DPllClose(DPLL1_MODULE);
    Clock_APllClose();
    
    // 降低核心电压
    Power_ConfigDCDC11(PWD_DCDC11_LVL_0V9);
    
    // 关闭 AVDD33
    Power_AVDD33Disable();
    
    // 进入睡眠
    Power_MemoryEnterSleep();
}
```

**步骤4：配置唤醒流程**

在 `main.c` 的 `WakeupMain()` 中配置：

```c
void WakeupMain(void)
{
    // 恢复电源
    Power_MemoryExitSleep();
    Power_AVDD33Enable();
    
    // 恢复核心电压
    Power_ConfigDCDC11(PWD_DCDC11_LVL_1V23);
    
    // 重新初始化芯片
    Chip_Init();
    SystemClockInit();
    
    // 重新初始化 Flash
    SpiFlashInit(84000000, MODE_4BIT, 0, 1);
    
    // 恢复 DAC
    AudioDAC_InitSniff();
}
```

**步骤5：编译验证**

重新编译工程，烧录到目标板，验证低功耗模式。

### 6.1 场景描述

需要实现固件升级功能（U盘/TF卡/蓝牙 OTA）。

### 6.2 开发步骤

**步骤1：启用升级功能**

在 `app_src/system_config/app_config.h` 中启用：

```c
#define CFG_FUNC_UPGRADE_EN    // 启用固件升级
```

**步骤2：配置升级方式**

在 `app_src/components/upgrade/upgrade.c` 中配置：

```c
// U盘/TF卡升级
void UsbCardUpgrade(void)
{
    if(SoftFlagGet(SoftFlagMvaInCard)) {
        // 从 TF 卡升级
        start_up_grate(SysResourceCard);
    } else if(SoftFlagGet(SoftFlagMvaInUDisk)) {
        // 从 U盘升级
        start_up_grate(SysResourceUDisk);
    }
}

// 蓝牙 OTA 升级
void BtOtaUpgrade(void)
{
    if(SoftFlagGet(SoftFlagBtOtaUpgradeOK)) {
        // 蓝牙 OTA 升级
        start_up_grate(SysResourceBtOTA);
    }
}
```

**步骤3：编译验证**

重新编译工程，烧录到目标板，验证固件升级功能。

## 7. 调试技巧

### 7.1 UART 日志调试

**启用 UART 日志**（`app_config.h`）:

```c
#define CFG_UART_LOG_EN    // 启用 UART 日志
```

**使用日志打印**:

```c
APP_DBG("Driver Version: %s\n", GetLibVersionDriver());
DBG("Main task MSG_POWER\n");
```

### 7.2 在线调试

**USB HID 在线调音**（`app_config.h`）:

```c
#define CFG_FUNC_AUDIO_EFFECT_ONLINE_TUNING_EN  // 启用在线调音
#define CFG_COMMUNICATION_BY_HS_USB             // 使用 HS USB HID
```

**UART 在线调音**:

```c
#define CFG_COMMUNICATION_BY_UART               // 使用 UART 通信
```

### 7.3 性能分析

**CPU 占用率分析**:

```c
// 在日志中查看 CPU 占用率
APP_DBG("CPU: %d M\n", CpuUsageGet());
```

**内存使用分析**:

```c
// 在日志中查看内存使用
APP_DBG("RAM: %d K\n", RamUsageGet());
```

### 7.4 常见调试场景

| 场景 | 排查方向 |
|------|----------|
| 系统进入 Safe Mode | 检查 `AudioEffect_Parambin_Check` 是否失败 |
| 音频无声 | 检查 Source/Sink 通路、DAC 初始化、FIFO 分配 |
| 蓝牙无法连接 | 检查 `bt_config.h` 配置、BT 地址、协议支持 |
| 编译报错 | 检查宏配置冲突、库依赖、路径 |
| 功耗过高 | 检查 DeepSleep 配置、GPIO 漏电、时钟门控 |

## 8. 开发流程总结

```
需求分析
  ↓

  ↓

  ↓

  ↓

```

### 8.2 常见问题排查流程

```
问题现象
  ↓
查看 UART 日志
  ↓
定位问题模块
  ↓
检查配置（app_config.h / bt_config.h / flow_config.h）
  ↓
检查代码逻辑
  ↓
修复问题
  ↓
重新编译验证
```
