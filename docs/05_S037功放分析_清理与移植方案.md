## 1. 音频拓扑（确认版）

```
LineIn → DSP(公共通路, MUSICGAIN固定0dB) ─┬─→ DAC_SINK → DAC寄存器 → HT97180 → 耳机   [耳机路独立]
                                          └─→ I2S1_SINK → I2S1(LRCLK/DOUT/BCLK)
                                                        ├─→ TWE功放(0x2C/0x58) → 全频喇叭
                                                        └─→ WF功放 (0x2D/0x5A) → 低音喇叭
                                                       （两颗功放共用同一路 I2S1 数据）
```

### 关键点

| 项 | 说明 |
|----|------|
| **单路 I2S1** | 两颗功放(TWE/WF)共用同一路 I2S1 的 LRCLK/DOUT/BCLK，音频数据完全相同 |
| **音量/静音独立靠寄存器** | 因两颗功放收到相同 PCM，DSP 共享增益(MUSICGAIN)无法区分二者，只能靠各自 I2C 寄存器独立控制 |
| **耳机路独立** | 不接功放，DAC 模拟输出直连 HT97180 耳放，走 DAC 寄存器控制 |
| **I2S2 不需要** | 原 S037 每功放一路 I2S；本设计共用 I2S1，故 I2S2 可关闭 |

## 2. S037 功放逻辑全景

### 2.1 启动调用链

```
rl_hw_bsp_init (rl_hwbsp.c)
 ├─ rl_hw_powergpio()             ← GPIOB2 拉高: 功放供电
 └─ amp_driver_init()             (amp_driver.c)
     └─ AMP_Init (AMP.c)
         ├─ GPIO 配置: B7(SCL) / B6(SDA) / B3(PDN)
         ├─ I2cMasterCreate(B7, B6) → AMP_I2cHandler
         └─ AMP_PowerOn (AMP.c)
             └─ ACM8625_PowerOn (ACM8625.c)
                 ├─ PDN 复位时序 (高10ms→低50ms→高50ms)
                 ├─ ACM86xx_init_TWE()  写0x58 → 全频  DSP表 + 0dB
                 └─ ACM86xx_init_WF()   写0x5A → 低音  DSP表 + 0dB
```

### 2.2 两颗功放芯片参数

| 芯片 | I2C 写地址 | 7-bit 地址 | 驱动喇叭 | 源文件 | 音量函数 | 静音函数 |
|------|-----------|-----------|---------|--------|---------|---------|
| **TWE** | 0x58 | 0x2C | 全频 | `ACM8625S_export_TWE.c/h` | `TWE_volumeControl(vol)` | `ACM86xx_Mute_TWE/UnMute_TWE` |
| **WF** | 0x5A | 0x2D | 低音 | `ACM8625S_export_WF.c/h` | `WF_volumeControl(vol)` | `ACM86xx_Mute_WF/UnMute_WF` |

### 2.3 引脚分配

| 信号 | GPIO | 说明 |
|------|------|------|
| I2C SCL | GPIOB7 | 软件 I2C 时钟 |
| I2C SDA | GPIOB6 | 软件 I2C 数据 |
| PDN | GPIOB3 | 功放掉电控制 |
| 功放供电 | GPIOB2 | `rl_hw_powergpio()` 拉高；必须在功放初始化前执行 |

> 注意: B6=SCL、B7=SDA 的 I2C0 引脚在 B6_Audio_SDK 中**被 HDMI DDC 占用**（`HDMI_DDC_IO_PIN = I2C0_PORT_B6_B7`），移植时需关闭 HDMI 相关宏。

### 2.4 功放函数调用方

| 调用点(文件:行) | 函数 | 用途 | 保留? |
|-----------------|------|------|--------|
| `rl_hwbsp.c` | `amp_driver_init()` | 开机上电功放 | ✅ 必需 |
| `rl_ui.c:661` | `AMP_PowerOn()` | 遥控/触摸开机再上电 | 🔸 裁剪外围后由新入口替代 |
| `rl_ui.c:645` | `AMP_PowerOff(0)` | 关机下电(注意签名不匹配：定义`(void)` 却带参调用) | 🔸 |
| `rl_ui.c:458/493/808/811/232` | `ACM8625_VolSet(vol)` | 音量(当前为空实现) | 🔸 待补 |
| `rl_ir.c:73` | `ACM8625_VolSet(vol)` | 遥控取消静音恢复音量 | ❌ 红外功能删除 |

## 5. 移植到 B6_Audio_SDK

### 5.1 直接移植的文件（双功放全保留）

```
app_src/rl_sdk/amp_driver/
├── AMP.c / AMP.h                  ← 抽象层(创建I2C句柄、上电、类型管理)
├── ACM8625.c / ACM8625.h          ← 芯片控制(PDN复位、Mute、VolSet)
├── ACM8625S_export_TWE.c/h        ← 全频功放(0x2C/0x58) DSP寄存器表+音量+静音
└── ACM8625S_export_WF.c/h         ← 低音功放(0x2D/0x5A) DSP寄存器表+音量+静音
```

### 5.2 B6_Audio_SDK 侧配套

| 文件 | 改动 | 原因 |
|------|------|------|
| `app_config.h` | 关闭 `CFG_APP_HDMIIN_MODE_EN` | 释放 B6(SDA)/B7(SCL) |
| `gpio_config.h` | HDMI DDC 块(需 `CFG_APP_HDMIIN_MODE_EN`)自动失效 | 同上 |
| `app_config.h` | 关闭 `CFG_I2S2_MIX_OUT_EN` | 双功放共用 I2S1，不用 I2S2 |
| 新增 `rl_hw_powergpio()` | 在功放初始化前拉高 B2 | 功放供电 |
| `AMP.c` | 确认引脚宏 B7/B6/B3 | 与硬件一致 |

### 5.3 依赖接口（B6 已具备，零新增）

| 接口 | 头文件 |
|------|--------|
| `I2cMasterCreate` / `I2cWriteNByte` / `I2cReadNByte` | `driver/driver_api/inc/i2c_host.h` |
| `DelayMs` | `middleware/mv_utils/inc/delay.h` |
| `GPIO_PortBModeSet` / `GPIO_RegOneBitSet/Clear` | `driver/driver/inc/gpio.h` |
| `APP_DBG` / `DBG` | `debug.h` |

## 6. DualOutput 音量/静音 API（串口协议阶段）

> 本阶段文档仅约定接口，功能实现在当前 SDK 上接入串口协议时完成。

### 6.1 接口定义

```c
typedef enum { OUT_HP=0, OUT_TWE, OUT_WF } OUTPUT_PATH;  // 耳机 / 全频 / 低音

void    DualOutput_Init(void);
bool    DualOutput_SetVol(OUTPUT_PATH p, int16_t vol);
int16_t DualOutput_GetVol(OUTPUT_PATH p);
bool    DualOutput_SetMute(OUTPUT_PATH p, bool mute);
bool    DualOutput_GetMute(OUTPUT_PATH p);
```

### 6.2 各路实现

| 输出路 | SetVol 实现 | SetMute 实现 | 音量查询 |
|--------|------------|--------------|----------|
| `OUT_HP`(耳机) | `AudioDAC_VolGainSet_For_dB(DAC_SEL, vol, vol)` | `AudioDAC_SoftMute(DAC_SEL, mute, mute)` | `AudioDAC_VolGet` |
| `OUT_TWE`(全频) | `TWE_volumeControl(vol)` (vol 0~16, 16=0dB) | `ACM86xx_Mute_TWE/UnMute_TWE` | 读功放寄存器/缓存 |
| `OUT_WF`(低音) | `WF_volumeControl(vol)` | `ACM86xx_Mute_WF/UnMute_WF` | 读功放寄存器/缓存 |

### 6.3 音量分配策略

- **DSP MUSICGAIN 保持固定 0dB**（直通），不做音量 —— 避免共享增益拖累三路联动
- 三路音量/静音全部落在**下游硬件寄存器**（DAC / 各功放），互不干扰，支持独立查询
